Overview

Hcode is a production-ready AI coding assistant that combines the power of large language models with a comprehensive toolkit for software development. It supports multiple LLM providers, integrates with external services, and provides both CLI and programmatic interfaces.

System Architecture

Hcode follows a modular, layered architecture that separates concerns and enables extensibility. The system is built around a core agent that orchestrates tool execution, manages context, and communicates with LLM providers.

High-Level System Architecture
Architecture Highlights: The layered architecture ensures clean separation of concerns. The Agent Core orchestrates all operations, while providers and tools remain decoupled and easily extensible.

ReAct Loop - Core Agent Workflow

The ReAct (Reasoning and Acting) pattern is the heart of Hcode's intelligence. The agent iteratively reasons about the task, takes actions using tools, observes the results, and continues until the goal is achieved.

ReAct Loop Execution Flow

ReAct Loop Phases

1

Reasoning Phase

The agent analyzes the user's request, breaks it down into manageable steps, identifies which tools are needed, and creates a mental model of how to solve the problem. This includes understanding context, constraints, and desired outcomes.

2

Action Phase

Based on the reasoning, the agent executes concrete actions using the available tools. This might include reading files, running commands, editing code, searching the web, or any combination of the 26+ available tools.

3

Observation Phase

The agent examines the results of its actions, verifies success or failure, updates its understanding of the situation, and determines whether the task is complete or if another iteration is needed.

4

Iteration

If the task isn't complete, the loop continues with new reasoning based on the observations. This iterative process continues until the goal is achieved or a stopping condition is met.

Python SDK Reference

The Python SDK provides a programmatic interface for integrating Hcode into your applications, scripts, and workflows. It offers both synchronous and asynchronous APIs.

Installation

Bash
# Install from repository pip install -e . # Verify installation hcode --version

Basic Usage

Python
from hcode.core import EnhancedHcodeAgent from hcode.providers import TaskComplexity, TaskType # Initialize agent with API keys agent = EnhancedHcodeAgent( anthropic_key="your-anthropic-key", openai_key="your-openai-key" ) # Simple task execution import asyncio async def main(): result = await agent.execute_task( task="Create a Python function to calculate fibonacci numbers", complexity=TaskComplexity.SIMPLE ) print(result) asyncio.run(main())

Troubleshooting

Common Issues

1

API Key Not Found

Solution: Ensure your .env file exists with the correct API keys. Check that you're running from the correct directory, or set environment variables explicitly.

2

Module Not Found

Solution: Make sure you installed the package with pip install -e . and that your virtual environment is activated.

3

Unicode/Emoji Errors on Windows

Solution: The application automatically detects Windows and uses safe alternatives. If issues persist, use Windows Terminal instead of cmd.exe or run chcp 65001.

4

Model Does Not Exist (Cerebras)

Solution: Use Cerebras-compatible models like llama3.1-8b or llama3.1-70b with --provider=openai --model=llama3.1-8b.

Debug Mode: Enable debug output with hcode run "task" --debug to see detailed API requests, tool executions, and internal state.
