Registered Capabilities

A complete registry of the 11 core tools that power the Hcode agent.

📄

File Operations

Read
Core

Reads file contents with intelligent chunking. Enforces an 800-line limit per read to protect context window. Supports partial views via start/end line arguments.

file_path str Absolute path to file
start_line int? 1-indexed start line
end_line int? 1-indexed end line
Write
Core

Writes content to files. Includes safety features like syntax checking for Python files and "preview mode" to verify changes before applying them.

file_path str Absolute path
content str Full file content
mode str 'overwrite' | 'append'
Edit
Precision

Performs precise string replacement. Requires unique match of `old_string`. Returns a unified diff of the change to confirm correctness.

file_path str Absolute path
old_string str Exact text to replace
new_string str New text content
LS
Discovery

Lists directory contents with type indicators (file vs dir) and size information. Supports ignore patterns to filter output.

path str Directory path
ignore str? Comma-separated globs
⚡

Execution Engine

Bash
RTE

Executes shell commands with cross-platform compatibility (Windows/Linux translation). Supports background execution and configurable timeouts.

command str Shell command
timeout int Max duration (ms)
background bool Run async?
BashOutput
Async

Retrieves stdout/stderr from background processes. Supports regex filtering and tail/head limiting to manage output size.

bash_id str Shell ID
filter str? Regex filter
🛡️

Navigation & Safety

Glob
Context-Aware

Searches for files matching patterns. Automatically excludes noise (like `node_modules`, `.git`) and limits results to prevent context overflow.

pattern str e.g., "**/*.py"
path str Search root
DiffPreview
Review

Generates a prospective diff for a change WITHOUT applying it. Performs safety checks for syntax errors, breaking changes, and security risks.

ApplyChange
Action

Commits a change that was previously approved via `DiffPreview`. Ensures that only reviewed code touches the filesystem.
